# Eval set sources — survey

A running inventory of peer-reviewed, public-data studies on LLM citation
hallucinations. Used to source the citecheck eval set without self-generation
bias (we don't want to evaluate citecheck on hallucinations citecheck itself —
or an LLM that thinks like citecheck — produced).

---

## v1 source (in use)

### Walters & Wilder (2023)

- **Paper:** "Fabrication and errors in the bibliographic citations generated by ChatGPT," *Scientific Reports* 13:14045
- **DOI:** [10.1038/s41598-023-41032-5](https://doi.org/10.1038/s41598-023-41032-5)
- **License:** CC-BY 4.0
- **N:** 636 citations from 84 papers (GPT-3.5 and GPT-4)
- **Labels:** explicit `Work itself is fabricated` boolean per row
- **Data:** Supplementary Appendix 3 (XLSX, 155 KB). Available without auth at the Springer static-content CDN: `https://static-content.springer.com/esm/art%3A10.1038%2Fs41598-023-41032-5/MediaObjects/41598_2023_41032_MOESM3_ESM.xlsx`. PMC's mirror has a proof-of-work challenge for downloads.
- **Coverage:** Generalist humanities + scholarly topics; ~half are books, which Crossref and OpenAlex index poorly. This is the realistic worst case for the hallucination detector.
- **Field bias:** mixed. Strongest on humanities; weakest on physical sciences.
- **Stored in repo:** `data/eval/raw/walters_wilder_2023_supp3.xlsx`

- **DOI:** [10.1177/05694345231218454](https://doi.org/10.1177/05694345231218454)

## Adding a new source

1. Download to `data/eval/raw/<source>_supp.<ext>` (keep the original format).
2. Add a parser path in `scripts/build_eval_set.py` (or a new script if the format diverges).
3. Each row in `labels.csv` should set `labeler` to the source key (e.g. `walters_wilder_2023`, `buchanan_2024`) so eval reports can break out per-source metrics.
4. Update this file with what's in the new source.

## What we are NOT using

- LLM-self-generated citations (asking ChatGPT/Claude/etc. to produce fakes for us). This loops citecheck back to its own training distribution and inflates recall. The whole point of using published datasets is independent labels.
- Manually-hand-labeled in-house corpora. Time-prohibitive for the launch, and the Walters & Wilder set is already large and well-labeled.
- "Mangled real refs" (synthetic perturbations of real refs). Useful for unit-testing the detector's individual layers but not a stand-in for naturally-generated hallucinations.
