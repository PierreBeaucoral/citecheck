# Hallucination evaluation set

This directory holds the labeled validation set for the Phase 3 hallucination detector. It is **built during Phase 1**, not Phase 3, so we have a held-out test set as the codebase grows.

The PDFs and labels themselves are gitignored — the actual files are stored separately (LFS or external storage, TBD) — but the labeling protocol and metadata schema live here.

## Goal

A labeled set of ~100 references such that we can compute, for the Phase 3 detector:

- **Precision** on flagged-hallucinated: of the references citecheck flags as hallucinated, how many actually are?
- **Recall** on hallucinated: of the truly hallucinated references in the set, how many does citecheck catch?
- **False-positive rate on real references**: how often does citecheck wrongly flag a real reference?

Phase 3's promise — "I ran citecheck on N papers and found M hallucinations" — is only credible if precision and FPR are measured on a held-out set.

## Composition target

| Class | Count | Source |
|---|---|---|
| Real, DOI-resolvable, mainstream journal | 30 | Random sample from arXiv/PMC OA, post-2010 |
| Real, no DOI (older or non-standard) | 15 | Pre-2000 economics/humanities, books, working papers |
| Real, in non-English journal | 10 | Crossref + DOAJ, filtered to non-English venues |
| Hallucinated by an LLM | 30 | Generated by asking an LLM for citations on a topic; manually verified non-existent |
| Real-but-mangled (typos, wrong year, swapped author) | 10 | Real references with controlled perturbations |
| From a retracted LLM-assisted paper | 5 | Documented cases in Retraction Watch's "AI-generated content" tag |

Total: 100. Class balance is deliberately tilted toward edge cases — pre-2000, non-English, mangled — because that's where false positives will hurt.

## Labeling schema

Each reference gets a row in `labels.csv` (gitignored — sensitive while under construction):

| Column | Type | Values |
|---|---|---|
| `id` | str | `eval_001` … `eval_100` |
| `raw_text` | str | The reference as it appears in the source PDF |
| `class` | str | `real_mainstream`, `real_no_doi`, `real_non_english`, `hallucinated`, `mangled`, `retracted_ai_paper` |
| `ground_truth_doi` | str or empty | DOI if real and resolvable |
| `expected_verdict` | str | `real_high_confidence`, `real_low_confidence`, `suspicious`, `likely_hallucinated` |
| `notes` | str | Why this label — link to evidence (Crossref query, OpenAlex page, etc.) |
| `labeler` | str | Initials of the human labeler |
| `verified_by` | str | Initials of the second labeler (for inter-annotator agreement subsample) |

A 20-reference subsample is labeled by two people independently to compute inter-annotator agreement (target: Cohen's κ > 0.8).

## How the eval is used

```
phase_3_detector(reference) -> verdict
                              ↓
                              compare to expected_verdict
                              ↓
                              precision, recall, FPR
```

Targets:
- Precision on `likely_hallucinated` verdicts: ≥ 0.9
- Recall on truly hallucinated references: ≥ 0.7
- FPR on `real_mainstream` references: < 0.05

If thresholds in the Phase 3 aggregator are tuned on this set, **a held-out 20% must be reserved** that is never touched during tuning.

## Provenance

- `corpus_definition.md` (to be added) records the exact arXiv categories sampled, the LLM model used to generate hallucinated references, and the date of sampling.
- This protects against the eval being silently overfit to whatever the test set happens to look like.

## Ethics

- All real references are to publicly available works. We do not include private/unpublished material.
- Hallucinated references are clearly marked as such and never propagated outside this dataset.
- Authors of "mangled" references are not contacted; the mangling is mechanical and the underlying real reference is preserved.
