{# Coffee-person SVG mascot — chibi pixel-art (16-pixel-creator aesthetic). Built on a 16-wide × 22-tall pixel grid. Each cell is 6px in the default 96×132 rendered size. Style choices match the 16pixel character-creator aesthetic: - Chibi proportions: head is 7×6 cells, body is 6×8 cells. - One-pixel dark outline around every visible region. - Bright flat colour blocks; no gradients. - Two-pixel eyes, single-pixel mouth. - Steam = a tall column of 3 staggered single pixels. Customisable parts use `.cp-*` CSS classes; defaults read from localStorage via mascot.js. Animations preserved (eye blink, steam rise, arm-cup sip tilt). #}
